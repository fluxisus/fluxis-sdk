## Requisitos previos

- **React 18 o 19** como dependencia de par en tu proyecto
- **Node.js 22+**

## Instalar

```bash
npm install @fluxisus/react
```

`@fluxisus/react` incluye `qrcode.react` como dependencia empaquetada — no necesitas instalarlo por separado.

## Dependencias de par

Declara `react` y `react-dom` como dependencias en tu proyecto si aún no lo has hecho:

```bash
npm install react react-dom
```

## TypeScript

El paquete incluye sus propias declaraciones de tipos — no se necesita ningún paquete `@types/`.

## Formatos de módulo

El paquete se publica en formato **ESM** y **CJS**, por lo que funciona en cualquier bundler moderno (Vite, webpack, Next.js, Remix) sin configuración adicional.
