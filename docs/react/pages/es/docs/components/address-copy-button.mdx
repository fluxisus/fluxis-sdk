---
title: AddressCopyButton
---

Muestra una dirección cripto truncada con un botón para copiar al portapapeles. Muestra "¡Copiado!" durante 2 segundos después de copiar.

Las direcciones de más de 14 caracteres se truncan al formato `primeros8…últimos6`. Las más cortas se muestran completas.

## Importación

```tsx
import { AddressCopyButton } from '@fluxisus/react';
```

## Uso

```tsx
<AddressCopyButton address="0x3c499c542cEF5E3811e1192ce70d8cC03d5c3359" />
```

## Props

| Prop | Tipo | Por defecto | Descripción |
|------|------|-------------|-------------|
| `address` | `string` | **requerido** | Dirección cripto completa o token NASPIP a mostrar y copiar |
| `className` | `string` | — | Clase CSS sobre el contenedor |

## Ejemplos

### Dirección de wallet

```tsx
<AddressCopyButton address="0x3c499c542cEF5E3811e1192ce70d8cC03d5c3359" />
// Muestra: 0x3c499c…c3359
```

### Token NASPIP

```tsx
<AddressCopyButton address={session.recipient_address} />
```

## Disponibilidad del portapapeles

`navigator.clipboard` requiere un contexto seguro (HTTPS o `localhost`). En orígenes HTTP planos la acción de copiar falla silenciosamente — el botón se renderiza igualmente, pero el estado "¡Copiado!" no se activa.
