---
title: PaymentStatusBadge
---

Badge inline con color que mapea el estado de una `CheckoutSession` a una etiqueta legible y un color de fondo.

| Estado | Etiqueta | Color |
|--------|----------|-------|
| `pending` | Pending | Azul |
| `confirming` | Confirming | Ámbar |
| `completed` | Completed | Verde |
| `expired` | Expired | Gris |

## Importación

```tsx
import { PaymentStatusBadge } from '@fluxisus/react';
```

## Uso

```tsx
<PaymentStatusBadge status={session.status} />
```

## Props

| Prop | Tipo | Por defecto | Descripción |
|------|------|-------------|-------------|
| `status` | `'pending' \| 'confirming' \| 'completed' \| 'expired'` | **requerido** | El estado de pago actual |
| `className` | `string` | — | Clase CSS sobre el contenedor |

## Ejemplos

### Junto a un resumen de pago

```tsx
<div style={{ display: 'flex', alignItems: 'center', gap: '0.5rem' }}>
  <span>Pedido #1234</span>
  <PaymentStatusBadge status={session.status} />
</div>
```

### Todos los estados

```tsx
<PaymentStatusBadge status="pending" />
<PaymentStatusBadge status="confirming" />
<PaymentStatusBadge status="completed" />
<PaymentStatusBadge status="expired" />
```
