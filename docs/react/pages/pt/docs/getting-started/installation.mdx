## Pré-requisitos

- **React 18 ou 19** como dependência de par no seu projeto
- **Node.js 22+**

## Instalar

```bash
npm install @fluxisus/react
```

`@fluxisus/react` inclui `qrcode.react` como dependência empacotada — você não precisa instalá-lo separadamente.

## Dependências de par

Declare `react` e `react-dom` como dependências no seu projeto, caso ainda não tenha feito:

```bash
npm install react react-dom
```

## TypeScript

O pacote inclui suas próprias declarações de tipos — nenhum pacote `@types/` é necessário.

## Formatos de módulo

O pacote é publicado em formato **ESM** e **CJS**, portanto funciona em qualquer bundler moderno (Vite, webpack, Next.js, Remix) sem configuração adicional.
