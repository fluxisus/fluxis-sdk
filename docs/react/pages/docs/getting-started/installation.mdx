## Prerequisites

- **React 18 or 19** as a peer dependency in your project
- **Node.js 22+**

## Install

```bash
npm install @fluxisus/react
```

`@fluxisus/react` ships `qrcode.react` as a bundled dependency — you don't need to install it separately.

## Peer dependencies

Declare `react` and `react-dom` as dependencies in your project if they aren't already:

```bash
npm install react react-dom
```

## TypeScript

The package ships its own type declarations — no `@types/` package needed.

## Module formats

The package is published as both **ESM** and **CJS**, so it works in any modern bundler (Vite, webpack, Next.js, Remix) without extra configuration.
